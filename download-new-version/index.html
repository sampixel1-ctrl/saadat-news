هنگام نصب، گوگل پیامی نشان می‌دهد. این پیام برای همه اپ‌هایی است که از فروشگاه گوگل نصب نمی‌شوند و خطری ندارد. مراحل زیر را دنبال کنید.

1 دانلود و باز کردن فایل

روی دکمه «دانلود نسخه 3.0» بزنید. بعد از اتمام دانلود، فایل saadat.apk را باز کنید. اگر گوشی پرسید، گزینه Settings را بزنید و Allow from this source (اجازه نصب از این منبع) را روشن کنید، سپس برگردید.

2 پیام Play Protect

صفحه‌ای با عنوان App scan recommended باز می‌شود. دو دکمه بزرگ آبی (Scan app و Don't install app) را نزنید. گزینه درست، متن کوچک بالای دکمه‌هاست:

این را بزنید

روی Install without scanning (نصب بدون اسکن) بزنید.

⚠️ اگر دکمه Don't install app را بزنید نصب لغو می‌شود. در این صورت دوباره فایل را باز کنید.

3 صبر تا پایان نصب

نوار Installing… پر می‌شود. چند ثانیه صبر کنید و دکمه Cancel را نزنید.

4 باز کردن برنامه

پس از پایان نصب، دکمه Open را بزنید یا آیکون قرمز «سعادت» را از صفحه گوشی باز کنید. تمام است ✅

اگر پیام مشابهی با دکمه‌های More details یا Install anyway دیدید، همان Install anyway را بزنید.
